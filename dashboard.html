M-D Plan4RES Method

Deterministic seasonal storage value via Benders cuts on the mean-inflow forecast.

\[ V_t(S)=\max_{\ell\in\mathcal{L}_t}\{\,b_\ell+\mathbf{a}_\ell^\top\mathbf{S}\,\} \]

M-S MOSSHOOS Method

Four coupled layers replace the deterministic assumption with a full stochastic treatment.

WP2 — Haar wavelet

\[ x_t=A_J(t)+\sum_{j=1}^{J}D_j(t) \]

WP2 — Fourier seasonal fit

\[ \theta(t)=a_0+\sum_{k=1}^{K}[a_k\cos(2\pi kt)+b_k\sin(2\pi kt)] \]

WP3 — Block-bootstrap scenarios

WP4-B — Itô SDE (OU / CIR)

\[ dQ_t=\kappa(\mu-Q_t)dt+\sigma\,dW_t \]
\[ dQ_t=\kappa(\theta-Q_t)dt+\sigma\sqrt{Q_t}\,dW_t \]

WP4-C — HJB control

\[ \rho J=\sup_u\{\mathcal{R}+(Q-u)J_V+\kappa(\mu-Q)J_Q+\tfrac{\sigma^2}{2}J_{QQ}\} \]
\[ u^*(V,Q)=\Pi_{[0,u_{\max}]}\!\big(\tfrac{b-J_V}{c}\big) \]

Where We Improve Plan4RES

1 · Inflow representation

Plan4RES: single deterministic mean \(\bar{Q}_t\) → MOSSHOOS: Haar wavelet \(x_t=A_J+\sum D_j\)

2 · Scenario generation

Plan4RES: none / i.i.d. → MOSSHOOS: block-bootstrap + K-means,

3 · Bellman values

Plan4RES: deterministic Benders cuts → MOSSHOOS: online SDDP over scenario set η

4 · Release policy

Plan4RES: stage-wise LP → MOSSHOOS: continuous-time HJB feedback under OU/CIR
